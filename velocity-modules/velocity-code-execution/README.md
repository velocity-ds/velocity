# velocity-code-execution

Docker-sandboxed Python `code_run` tool (`agent.codeexecution`): sandbox client, durable runs and
artifacts, recovery worker, task code-run routes, and the bundled `pdf` and `xlsx` skills. Needs
the image built from `runtime/code-execution-runtime/`.

Guide: [docs/code-execution.md](../../docs/code-execution.md).
